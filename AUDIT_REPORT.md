# AfterGlow Repository Audit

**Audit date:** 2026-11-05  
**Branch:** `cleanup/production-framework-and-audit`  
**Scope:** production framework, fabricated event data, and documentation cleanup

## Current state

The repository has been consolidated toward **Next.js App Router** on this branch. The package scripts now invoke `next dev`, `next build`, and `next start`; TypeScript is scoped to `app/`, `components/`, and `lib/` and excludes the legacy `src/` Vite app.

The legacy Express/Vite entrypoints (`server.ts`, `vite.config.ts`, root `index.html`, and legacy `src/App.tsx`, `src/main.tsx`, `src/index.css`) were removed. The hand-authored fixture `src/data/mockEvents.ts` was deleted. This removes the fabricated event feed from the previous Vite runtime instead of merely relabeling it.

## Framework decision

**Canonical production framework: Next.js.** The repository already had the App Router, Next route handlers, and `next.config.ts`. Its prior `package.json` was inconsistent: scripts launched Express/Vite and dependencies declared Vite, while the lockfile already described Next.js/React 19. This branch updates `package.json` to Next.js scripts/dependencies and updates `tsconfig.json` to include the Next app and alias.

## Fabricated information removed

The deleted legacy `server.ts` had:
- fallback Ticketmaster price ranges and default prices;
- fee and total-price calculations not supplied by Ticketmaster;
- invented SeatGeek and DICE listings, fees, inventory, deal labels, and stock;
- fixed reliability scores and ratings;
- random review counts;
- fallback dates/times/doors-open values and generated lineups/descriptions.

The deleted `src/data/mockEvents.ts` contained invented event names, dates, performer/venue descriptions, ratings/review counts, pricing tiers, inventory, and unsupported marketplace comparisons. These were fixtures, not real event/provider records.

The canonical Next.js Ticketmaster mapper currently exposes provider event name/date/venue/city/image/link and optional coordinates. It does not synthesize marketplace prices. Prices, fees, inventory, ratings, and availability must remain absent unless a provider explicitly supplies them.

## Remaining caution

- The package lockfile was not regenerated by npm. Its existing dependency root was already Next.js/React 19, but its metadata was previously named `ticket-site`; verify/regenerate the lockfile locally with `npm install` before relying on `npm ci`.
- The old Vite `src/` subdirectory and its component files remain in the repository as unreferenced legacy source, but are excluded from the Next.js TypeScript build. The app entrypoints and fabricated fixture file were removed.
- Local dependency installation, typecheck, lint, production build, and API smoke tests were not run through GitHub file editing. The PR is draft until these checks run from the local checkout.
